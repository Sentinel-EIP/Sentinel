# PARCOURS INNOVATION
## `< ATELIER - DIVERSIFICATEURS />`

Les instructions de cet exercice sont très simples, vous devez répondre à une question qui commence par :
> *« Quelle serait notre idée de projet si nous devions... »*

### 1. Choisissez votre périmètre
* ... protéger des systèmes contre les cybermenaces ;
* ... développer une application basée sur l'IA et le ML ;
* ... développer une application basée sur la blockchain ;
* ... concevoir un moteur de jeu multi-plateforme.

### 2. Éventuellement, choisissez deux diversificateurs
* la fonctionnalité principale peut être utilisée en 30 secondes ou moins ;
* l'UX est différente selon la langue et/ou le pays sélectionné ;
* la taille du fichier de mon projet est limitée à 64 Ko ou moins ;
* la fonctionnalité principale peut être utilisée pendant un appel vidéo ;
* nous devons utiliser l'API d'un réseau social ;
* nous devons utiliser des gyroscopes et des accéléromètres ;
* nous devons utiliser l'API OpenStreetMap pour intégrer des données de géolocalisation ;
* nous devons utiliser un moteur ou framework open source peu connu ;
* nous nous concentrons sur le thème de la désinformation ;
* nous devons utiliser un langage de programmation ésotérique ;
* nous devons randomiser quelque chose qui ne serait traditionnellement pas randomisé ;
* nous devons utiliser une ou plusieurs API d'accessibilité système/OS ;
* nous agissons en faveur des objectifs de développement durable ;
* la fonctionnalité principale de notre projet est affectée par la météo réelle ;
* il est possible pour les utilisateurs de modder notre projet, sans qu'ils aient besoin de recompiler l'exécutable du projet à partir de notre code source.

---

## Exemples

**Exemple 1**
> **Question :** « Quelle serait notre idée de projet si nous devions développer une application basée sur l'IA et le ML et que nous nous concentrons sur le thème de la désinformation et que la fonctionnalité principale peut être utilisée pendant un appel vidéo ? »
>
> **Idée :** « Je voudrais créer un projet pour les streamers de la catégorie "Just Chatting", fournissant un retour en temps réel sur les informations provenant du chat ou de sites web pendant leurs streams. Cette initiative vise à empêcher les streamers d'être induits en erreur par la désinformation. »

**Exemple 2**
> **Question :** « Quelle serait notre idée de projet si nous devions concevoir un moteur de jeu multi-plateforme et que nous devons randomiser quelque chose qui ne serait traditionnellement pas randomisé et que nous devons utiliser des gyroscopes et des accéléromètres ? »
>
> **Idée :** « Je souhaite développer un moteur de jeu avec une physique randomisée, garantissant que chaque partie offre une expérience unique sans modifier le code source du jeu. Spécifiquement conçu pour les plateformes mobiles, ce moteur intègre parfaitement le gameplay à physique aléatoire avec les gyroscopes et les accéléromètres. C'est une excellente opportunité pour explorer un gameplay innovant. Le principal défi réside dans la capacité à offrir de manière constante une expérience de jeu jouable. »

## Aide

Vous pouvez utiliser ces questions pour vous aider à trouver de nouvelles idées :
* Quels nouveaux avantages et fonctionnalités pourraient émerger du diversificateur imposé ?
* Qu'est-ce que le diversificateur exactement ?
* Quels éléments clés sont en opposition ?
* Est-il possible d'introduire quelque chose au début ou à la fin du processus pour modifier les éléments en opposition ?
* Le temps, l'espace, les matériaux ou l'environnement exercent-ils une influence ?

## Livrable

Le fichier livré sera nommé **"diversifier_nomdugroupe.pdf"**.

Vous devez générer **3 idées** et les formaliser dans un diaporama.

**Pour chaque idée :**
* **Slide 1 :** la question que vous avez utilisée pour générer votre projet : *« Quelle serait notre idée de projet si nous devions [Périmètre] et [diversificateur 1] et [diversificateur 2] ? »*
* **Slide 2 :** votre idée de projet et expliquez comment elle répond à la question.

Vos idées de projets seront évaluées selon 3 critères :
* l'ambition technique et l'utilisation de technologies avancées ;
* l'originalité et la créativité de la solution que vous proposez ;
* la facilité pour l'évaluateur de comprendre votre idée.
