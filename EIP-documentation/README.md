# EIP — Documentation SENTINEL

## Arborescence

- `deliverables/` : documents produits par l'équipe (plans, roadmap, policies).
- `workshops/guides/` : consignes ateliers en markdown.
- `workshops/pdfs/` : supports PDF et références officielles.
- `context/` : contexte fonctionnel et narratif du projet.

## Convention de nommage

- Préfixe `sentinel_` pour les livrables produits par l'équipe.
- Préfixe `reference_` pour les documents externes/de consignes.
- Préfixe `workshop_` pour les supports atelier.

## Note

Les noms de fichiers PDF ont été normalisés quand ils étaient ambigus (`day2.pdf`, `cost.pdf`, etc.) afin de rendre le contenu explicite sans ouvrir chaque fichier.

Les contenus hors scope **Track Solution** (notamment video game) ont été retirés du workspace.
