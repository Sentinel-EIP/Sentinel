# EIP - Documentation Sentinel

## Arborescence

- `deliverables/` : documents produits par l'equipe (plans, roadmap, policies).
- `workshops/guides/` : consignes ateliers en markdown.
- `workshops/pdfs/` : supports PDF et references officielles.
- `context/` : contexte fonctionnel et narratif du projet.

## Convention de nommage

- Prefixe `sentinel_` pour les livrables produits par l'equipe.
- Prefixe `reference_` pour les documents externes/de consignes.
- Prefixe `workshop_` pour les supports atelier.

## Note

Les noms de fichiers PDF ont ete normalises quand ils etaient ambigus (`day2.pdf`, `cost.pdf`, etc.) afin de rendre le contenu explicite sans ouvrir chaque fichier.

Les contenus hors scope **Track Solution** (notamment video game) ont ete retires du workspace.
