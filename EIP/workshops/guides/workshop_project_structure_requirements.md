# PARCOURS INNOVATION
## `< STRUCTUREZ VOTRE PROJET />`

**Structurez votre projet**

L'objectif de ce guide est de s'assurer que votre EIP est sur la bonne voie avant votre semestre international.

En suivant ce guide, vous établirez les fondations nécessaires pour que votre projet fonctionne correctement et préparerez tous les éléments essentiels pour la validation finale du diplôme. Votre EIP est une étape clé de votre cursus et sera évalué selon les critères d'évaluation RNCP.

---

## Pendant votre stage

Dans le cadre de votre EIP, vous devez mettre en place une base solide pour votre projet pendant votre stage. Cela comprend :
* La mise en place de votre dépôt.
* L'implémentation d'un pipeline CI/CD.
* La définition d'une politique de tests claire.
* La structuration de votre environnement technologique.

---

## Documentation requise

Vous devez préparer les documents Markdown suivants :

1. **`deployment.md`** - Un guide décrivant comment est configuré votre dépôt et votre pipeline CI/CD qui peut être utilisé pour construire, tester et déployer votre projet.
2. **`testing_policy.md`** - Un document définissant les politiques de tests, les stratégies de déploiement, les types de tests et les attentes en termes de couverture.
3. **`technology_environment.md`** - Un guide qui décrit l'environnement technologique de votre projet.

---

## Mise en place de votre dépôt

* Définissez une stratégie de branches claire (main, develop, feature branches).
* Implémentez un pipeline CI/CD qui peut être utilisé pour construire, tester et déployer votre projet.

---

## Politique de tests

Votre projet peut être testé avec différents types de tests :
* Tests unitaires
* Tests d'intégration
* Tests de bout en bout (End-to-End)
* Tests de sécurité et de performance
* Couverture de code

---

## Environnement technologique

Après les deux premières semaines de prototypage, vous commencez à définir l'environnement de votre projet ; il est maintenant temps de le renforcer :

* **Technologies et bibliothèques :** Assurez-vous que vos choix de technologies et de bibliothèques sont toujours maintenus, bien documentés et à jour.
* **Infrastructure et déploiement :** Définissez l'hébergement, la base de données et les dépendances de services, et listez toutes les spécifications nécessaires pour le développement et le déploiement.
* **Besoins matériels :** Si vous avez besoin de matériel spécifique pour votre projet, listez-le et justifiez votre choix.

---

## Prochaines étapes

* Mettez régulièrement à jour votre documentation.
* Commencez à implémenter les fonctionnalités de base de votre projet.
* Assurez-vous que tout est en place avant votre semestre international.
